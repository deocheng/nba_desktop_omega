## 0. 一句话结论

**路线 A（DINOv2 躯干外观 gallery + 后处理 k-NN 重连）无法过门①-B。** 实证扫描显示：要么零改善（遮挡分裂模型不匹配真实失败模式），要么「replace 降了但 Δ10 崩了」（错并不同球员，假完整）。根因是 **DINOv2 躯干嵌入被球衣颜色主导，同队球员/同一球员碎片不可分**——这是外观信号本身在篮球场景的退化，不是 stabilize 参数或匹配逻辑能修的。

## 2. 判读

### 2.1 路线 A 原设计前提不成立
`A_clean`（只合并「A 在 B 出生前已死」的遮挡分裂对）在 τ=0.6→0.9 **全程零改善**（replace 恒 10，Δ10 恒 ~0.169）。
- 深挖 ep15_s0 的 replace 事件（7→6、6→17、7→17）：涉及 track 6/7/17 的时间区间**高度重叠**（6:0–219、7:0–219、17:112–219），彼此相似度 0.83–0.93。
- 这说明主失败模式是「**同一球员被碎片化成多条并发 track**，持球人角色在碎片间跳」，**不是**「长遮挡→track 死亡→新生 ID」。路线 A 的「死亡后重生重连」模型整体打空。

### 2.2 放宽到合并重叠碎片：无有效工作点（假完整陷阱）
- 激进（τ=0.60）：replace 0、twin 0、two_real 16 → 看似完美，但 **Δ10 从 0.169 崩到 0.094**，外观审计 PASS 0/5。审计抓到这是**错并不同球员**（同队两位球员被并成一个 id）。
- 保守（τ=0.90）：replace 仅降到 8、Δ10 反而 0.1425（比基线更低）、err 30.8%。
- **结论：没有任何 τ 能同时「降 replace」且「不崩 Δ10」。** 这正是 §5.8 已确立的「单指标可博弈」铁律的再次验证。

### 2.3 根因：外观信号在篮球场景退化
- DINOv2 躯干嵌入被**球衣颜色主导**；同一队两名球员（及同一球员的不同时段碎片）余弦 0.83–0.93，与「不同球员」无法区分。
- 审计的 between-track 基线本就偏高（同帧不同球员多为同队），Δ10 余量极小（基线仅 0.169，门①-B 要求 ≥0.15 勉强踩线）。
- 团队标签本身由同一套嵌入 kmeans 得来，亦不可靠（ep15_s0 中 6 标队1、7/17 标队0，但三者相似度 0.83+）。

## 3. 推论：路线 B / C 也大概率救不了

- **路线 B（改 stabilize 内核：EMA→bank + 死亡 gallery 每帧检索）**：用的仍是同一 DINOv2 嵌入。扫描已证明「即使假设已知身份、完美合并」（B_overlap 高 τ 端）也救不回 Δ10——信号本身退化，换匹配逻辑无济于事。
- **路线 C（专用 re-id 模型，如 BoT-SORT with_reid + osnet）**：唯一可能突破的方向是**更强的身份判别信号**。但篮球同队球衣场景下，通用 re-id 模型（多基于服饰/体态）同样受球衣主导；真正能区分同队的是**球衣号码 / 面容**，而号码 OCR 在转播场景下可靠性低（见记忆：号码 OCR 无判别力）、面容在远景不可得。
- 故路线 C 成本高风险大，未必优于「正式接受门①-B 为已知架构边界」。

## 4. 建议（待老程裁定）

门①-B 身份正确性 = **当前跟踪器架构 + 篮球同队球衣外观退化** 共同导致的结构性瓶颈，**不是 stabilize 参数或 DINOv2 外观重连能解**。建议二选一，由老程定：

1. **（务实）正式接受门①-B 为已知架构边界**：维持 gate=0.30（norm_g3 不动），红线② Valen **维持锁**；在文档中明确「身份正确性受限于外观信号退化，非调参/外观重连可解」，避免后续重复投入。
2. **（进取）升级到更强身份信号再试**：优先探索「球衣号码识别」作为同队判别特征，或评估专用 re-id 模型（路线 C）在篮球数据上的可行性——但这是一条独立、高成本的新路线，需单独立项与预算。

老程采纳选项 1：**门①-B 正式判定为已知架构边界，停止在该方向的重复投入**。

2. **红线② Valen 维持锁**——门①-B 身份正确性确证不可解（参数 + DINOv2 外观重连均证伪）。
