## 0. 为什么做这个探针

A4.34/A4.35 之后我给 f00205 注入了补标真值球位 (719,339)（26px 框），但**注入框的
conf1/conf2 是用该 bank 里 TP 候选中位数填充的**（conf1=0.587 / conf2=0.208），
不是实测值。这有两个隐患：

1. **评测失真**：填充值是 TP 中位数（偏有利），头若仍给低分，不能排除"特征被美化后仍失败"；
2. 🔴 **训练污染**：真值球位**实测 conf1 只有 0.054**（见 §2），填成 0.587 等于教头
   "这种外观的球 conf 很高" —— 恰好把「低 conf 也可能是球」这个**最需要被学习的信号抹掉**。

因此本轮做两件事：① 在真值球位上**实测**检测器响应；② 把 conf 填充改成实测。

## 1. 🔴 自我推翻：上一轮的解释只对了一半

上一轮结论是「头在这个位置看不见球（位置扫描 75 框 max 仅 0.0444）」。
本轮实测后**更准确的分层**是：

| 层 | 事实（实测） | 判定 |
|---|---|---|
| 检测器（tile 口径） | 真值球位 **有响应**：框 `[707,319.6,750.4,381.6]` conf **0.054**，中心距真值球心 **15.1px** | ⚠️ 半可见 |
| 该框的形状 | **43×62px**（真球先验 p25/med/p75=20/22/25、max 33）⇒ IoU 仅 0.239 | ❌ 框严重偏大（球+手臂糊在一起） |
| 该检测的 conf 排名 | 按 conf1 降序排 **45/58**；该帧 conf1 中位数 **0.068** ⇒ 真球 conf **低于中位数** | ❌ conf 零区分度 |
| 现役 top-4 截断 | 被截断（池内没有它） | ❌ 丢掉 |
| 头（全量 58 候选池） | 该框 prob=**0.0016**，排序靠后；58 个里 **prob≥0.3 的 = 0 个**（最高 0.2558） | ❌ 头也认不出 |
| 头（注入 26px 合成框，实测 conf） | prob=**0.0054**（填充版 0.0069） | ❌ 同样认不出 |

**结论修正**：不是"头看不见球"这么单一，而是
**检测器给了个低 conf 且形状错误的框（球与手臂同色糊在一起） ⇒ conf 截断丢掉 ⇒ 头认不出**。
三层各自都失败，且**conf 特征在这帧完全无信息**（真球 conf < 候选 conf 中位数）。

## 3. 🔴 真 bug 修复：`manual_to_candidates.py` conf 填充 → 实测

**旧行为**（已废弃）：`conf1/conf2 = bank 内 TP 候选中位数`（f00205 填 0.587 / 0.208）。
**新行为**：跑现役口径检测器实测——
```
conf1 = tile 检测(640×384/ov96/thr0.05, 不截断) 中，中心距补标点 ≤ --match-r(默认20px) 的最高分
conf2 = 256px 裁切 → 384² → 与注入框 IoU>0.3 的最高分
```
同时把 TP 中位数写进 `conf1_tpmedian/conf2_tpmedian`（仅诊断，**不再入模**），
并把 `matched_tile_det`（匹配到的真实检测框/分数/中心距）与 `crop_window` 一起记进 bank 的
`measure` 字段，供审计。

**为什么这是"真 bug"而不只是"口径选择"**：填充让正样本携带了"高分"特征，
训练后头会学成「球 ⇒ conf 高」，而这正是它漏掉 f00205 的**根因**。
用填充值训练 = 把这个规律训得更强 = 越练越漏。已重跑注入：

```
[out] sas_lal_cands_manual.json     补标注入 1 个候选（f00205 #4 = (719,339) 26px）
[out] sas_lal_label_bank_manual.json 样本 268（pool=267 / manual=1）
      manual 记录: conf1=0.054  conf2=0.0  conf_source=measured  vis=clear
```

## 5. 结论与影响

1. ✅ **补标工具链已可信**：conf 现在实测，可用于训练与评测（不再有特征美化）。
2. 🔴 **A4.35 的结论要升级表述**：上限 71.2% 的**性质**不是"球没被检出"，
   而是「**球被检出但 conf 落在候选分布中位数以下 + 框形状错误 ⇒ 任何 conf 截断都丢掉**」。
   这解释了两件事：为什么 top-4→top-16 扩容无用（真球排 45/58，扩容到 32 也够不着），
   以及为什么"只看 conf 排序"的做法注定失败。
3. 🔴 **conf1 特征在此类帧上零特异性**（真球 conf < 中位数）⇒ 与 A1「指标特异性先自证」同族：
   **凡真球 conf 落在候选 conf 分布下半区的帧，conf 特征不可作为判定依据**。
4. ⚠️ **`conf2` 对真球也几乎无信号**（对照 0.081）⇒ 头的判别力实际来自裁切外观特征。
5. ❌ **f00205 这一帧在检测器层与头层双失败**，单帧补 1 个样本救不了它。

## 6. B 方案已执行：「球紧贴球员 ⇒ conf 低」假设的统计检验

数据：`sas_lal_label_bank_human.json`（TP=38 / FP=229）× `sas_lal_players.json`（逐帧球员框）。
口径：球框中心是否落在某球员框内（`inside`）+ 与最近球员框的中心距。

| 组 | 球心在球员框内 | 贴人组 conf1 中位 | 不贴组 conf1 中位 | 最近球员框中心距 p25/med/p75 |
|---|---|---|---|---|
| **TP（真球）** | **68.4%**（26/38） | 0.544 | 0.635 | 44 / 68 / 101 px |
| **FP（误检）** | 34.9%（80/229） | 0.354 | 0.331 | 90 / 161 / 331 px |

- ✅ **真球贴人是常态**（68.4%，是 FP 的两倍）⇒ 「球心落在球员框内」本身是一条**有用的正先验**
  （FP 只有 34.9%）。
- ✅ **贴人确实压低 conf**：TP 组「不贴人中位 0.635 − 贴人中位 0.544 = +0.091」，
  **置换检验 p = 0.0452（N=20 000）** —— 边缘显著，方向与假设一致。
- ❌ **但效应量不足以解释 f00205**：f00205 真值球 conf1 = **0.054**，
  远在 TP 贴人组分布之外（该组中位 0.544）。⇒ 「贴人」不是单一充分因素，
  **f00205 是「贴人 + 强遮挡 + 与皮肤同色」的极端个例**。
- ⚠️ 旁证：f00205 的 58 个垃圾检测里，贴人组（n=20）conf 中位 0.083 vs 不贴组（n=38）0.068
  —— **在垃圾检测中贴人与否对 conf 无区分度**，说明该帧的 conf 整体塌陷。

**对补样策略的直接含义**：按「贴人」补样本**覆盖不到** f00205 这类个例；
补样必须**按 conf 分位分层**（专门补"低 conf 真球"），否则头部训练分布里
"真球 conf ≥ 0.5" 的规律依旧成立，头会继续把低 conf 真球判负。
