## 二、🔴 自动标定不可行（三条独立证据）

我尝试了三条自动路线，**全部失败**。这不是"调阈值"能解决的：

### 2.1 复用已有 `court_infer_lines.py` → 失败
```
ep10_s0 f40/f70/f100/f130/f160 → why: 油漆区宽边线不足, poly: None
```
根因：该脚本 docstring 自述是**为 ep24_s1 构图**（近端底线在画面内）写的**直线推断器**，而 ep10 是**横屏侧视/斜角转播镜头**，前提不成立。

### 2.2 木地板掩膜分割 → 失败（跨域不可用，A5.14 已记录）
最大连通域占画面比例与填充率极不稳定：
```
ep10_s0:  2.5%画面, fill=0.33
ep13_s1: 13.5%画面, fill=0.50
ep17_s0: 20.4%画面, fill=0.79
ep20_s0:  7.8%画面, fill=0.18   ← 红色地板场, 掩膜几乎失效
```
凸包顶点 3~6 个不等，**无法稳定定出 4 角**。

### 2.3 篮筐橙环检测 → 失败（不可用作标定锚点）
跨 163 段扫描，橙环 x 中位从 47跳到 1242，**把球和观众衣服当成了篮筐**。虽然 143/163 有检出，但位置离散度大到无法作为标定锚点。

## 三、🔴 新事实 1：镜头几何逐段不同 ⇒ 标定粒度是「每段」不是「每期」

我原以为 11 期共用一个镜头，**错了**。按白线走向聚类（22 段，各取中段帧）：

| 段 | 主走向 | 段 | 主走向 |
|---|---|---|---|
| ep10_s0 | **0°**(28) | ep16_s1 | 0°(60) |
| ep10_s1 | **-45°**(555) | ep17_s0 | 0°(530) + -15°(388) |
| ep11_s0 | 0°(41) | ep17_s1 | 0°(18) |
| ep11_s1 | -45°(555) | ep18_s0 | -45°(568) |
| ep12_s0 | 0°(11) | ep18_s1 | 0°(31) |
| ep12_s1 | 0°(19) | ep19_s0 | 0°(52) |
| ep13_s0 | 0°(2) | ep19_s1 | -45°(522) |
| ep13_s1 | -45°(557) | ep20_s0 | -45°(564) |
| ep14_s0 | -45°(530) | ep20_s1 | -45°(574) |
| ep14_s1 | -45°(572) | ep15_s0 | 0°(186) |
| ep15_s1 | -45°(561) | ep16_s0 | 0°(24) |

**同一期内s0/s1 走向都不同**（ep10: 0° vs -45°；ep14: -45° vs -45°但不同帧；ep18: -45° vs 0°）⇒ **标定必须逐段做，22 段 = 22 次点选**。

目视核实两类构图（`/tmp/multi_ep_grid.jpg`、`/tmp/ep10_grid.jpg`）：
- **0° 类**（ep10_s0 / ep17_s0）：篮筐在画面左，球场向右延伸 ⇒ **场地深度轴 ≈ 画面 x 轴**。这与代码假设的「深度=y」**方向相反**。
- **-45° 类**（ep13_s1 / ep19_s1 / ep20_s0）：**斜角构图**，球场沿对角线展开，两个方向都不与画面轴对齐。

⇒ 印证上一份报告的 P0 结论，且**比原判断更严重**：不是"坐标系没变换"，而是**深度轴与画面轴夹角逐段不同**（0° 或 -45°），单一变换无法覆盖。

### 4.2 两个自动指标互相矛盾 ⇒ 自动判污染也不可靠

## 五、🔴 对 hit@k 的影响：这可能才是主要阻塞

把 §三+§四 代入上一份报告的 P0 结论：

- 需要标定的 22 段里，**约一半含图版/标注污染**，其球员坐标不是场地坐标 ⇒ 即便标定成功，投影结果也**不可信**。
- 上一份报告的 `SCREEN.CROSS 52 : SCREEN.DOWN 10 = 5.2:1` 反常，**污染段是候选解释之一**：图版上的红色标注/箭头会产生大量虚假"白线"，干扰 `_screen_sub` 的方向主导轴判定。

⇒ **建议先做「语料净化」再标定**，否则可能白标22 次。这个顺序问题需要老程裁定（见 §七 选项 B）。

## 七、待老程裁定

**A（原选项）= 直接接P0 标定**
- 前置：**老程为 22 段点选 4 条线**（约 176 点+ 22 次目视验证）
- 风险：**可能白做** —— 约半数段含图版污染，投影不可信（§五）

**B（🔴 新增，我建议先做这个）= 先净化语料，把图版/标注污染段剔除或分离**
- 做法：先做镜头切换点统计 + 图版段分离，剩下的**纯净段**再标定
- 收益：标定工作量可能从 22 段降到 ~11 段；且避免在脏数据上产出"看似正确的投影"
- 符合铁律：「系统性失败数据必须诚实呈现，不在错位数据上产出对齐看似正确的图」（A5.27fit_quad 教训）

**C = 只在纯净段上跑 A**，图版段单独归为「战术讲解素材」另作处理（它本身可能是有价值的战术语义来源，与你提供的战术板动画同类）

**我的建议顺序：C → B → A**。理由：先确定"哪些段值得标定"，再决定标定粒度，最后才做单应接入。**在约半数段不可信的前提下直接投22 次人工点选，风险偏高。**
