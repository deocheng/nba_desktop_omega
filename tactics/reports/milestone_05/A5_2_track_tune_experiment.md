# A5.2 单段跟踪对照实验（球员 ID 碎片化 · 参数扫描）

> 日期：2026-09-30 ｜ 承接 A5.1（根因=上游跟踪，`segment_detect_track.py` 自研 SORT-lite）
> 段：ep1_s0（221 帧 @1280×720）｜ 检测缓存复用（imgsz=1280，14.8s）

## 0. 一句话结论

**参数调优有真实增益但天花板有限**：`max_missed 3→30` + `GATE_POS 0.16→0.40`
把 ID 数从 **183 降到 108（−41%）**、中位寿命 **9→24 帧（2.7×）**，且**每帧人数逐帧不变**（硬门 PASS）；
但场上仅 ~13 人，108 ID 仍是 **~5–8× 碎片**。⇒ 调参是"必要的第一步"，**不是终点**。

## 1. 为什么扫这三组参数（定位）

`engine/segment_detect_track.py` 的人跟踪 = 自研 SORT-lite：
- 代价 = `W_POS·(脚点位移/H) + W_SIZE·|ln(h_pred/h_det)| + W_IOU·(1−IoU)`
- **`GATE_POS=0.16`**（脚点位移门，× 画面高）、`GATE_SIZE=0.90`
- **`max_missed=3`** ⇒ **漏检 >3 帧(0.3s) 轨迹即死、重开新 ID** ← 碎片化的直接机制
- `conf_person=0.25`

## 2. 实验一：max_missed 与 conf_person

| 配置 | ID 数 | 中位寿命 | 每帧人数(硬门) | 长续接 |
|---|---|---|---|---|
| base conf.25 mm3 | 183 | 9 | 20.4 | 15 |
| mm=8 | 158 | 10.0 | 20.4 | 42 |
| mm=15 | 150 | 11.0 | 20.4 | 50 |
| **mm=30** | **138** | **12.5** | **20.4 ✓** | 71 |
| mm=15 conf=.15 | 223 ↑ | 11 | **28.2 ✗** | 83 |
| mm=30 conf=.12 | 226 ↑ | 20 | **32.1 ✗** | 61 |

- **base 复现 183 ID**（吻合 A5.1 全局中位 187）⇒ 管线一致。
- **mm 3→30：ID −24.6%，每帧人数不变**（干净增益）。
- **降 conf 反而 ID 涨**（20.4→28.2 人/帧，多的是噪声）⇒ 排除"降阈值捞更多"。

## 3. 实验二：隔离 GATE_POS（conf 固定 0.25，检测人数恒 20.4）

| 配置 | ID 数 | 中位寿命 | 每帧人数 | 长续接 |
|---|---|---|---|---|
| base mm3 gate.16 | 183 | 9 | 20.4 | 15 |
| mm30 gate.16 | 138 | 12.5 | 20.4 | 71 |
| mm30 gate.25 | 130 | 16.0 | 20.4 | 50 |
| **mm30 gate.40** | **108 (−41%)** | **24.0 (2.7×)** | **20.4 ✓** | 27 |
| mm30 gate.25 sz1.3 | 123 | 20 | 20.4 | 47 |
| mm50 gate.40 sz1.3 | 113 | 21 | 20.4 | 24 |

- **放大 GATE_POS 是关键杠杆**：0.16→0.40 让 ID 再降 138→108，寿命翻倍。
- 附带现象：gate 放宽后 **长续接下降（71→27）**——因为在帧内就能关联上，不必靠 coasting。
- 全部配置**每帧检测人数恒 20.4**（硬门：拼接/调参不得增删检测）。

## 4. 诚实边界（必读）

1. **每帧人数不变 ≠ 跟踪正确**：它只保证"不丢检测"，**不能证明没有 ID 错并**。
   `gate.40`（≈288px/帧位移门）已相当宽松，**存在把相邻球员串号的真实风险**；
   `长续接` 列只是 coasting 量的**指示**，不是错并的直接度量。
2. **未做逐条目视裁定**：错并的真值判定权归老程；本实验只给"数量层"的证据。
3. 单段结论，**换段需复验**（不同素材人数密度不同）。
