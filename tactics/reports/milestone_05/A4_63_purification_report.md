# A4.63 候选池净化（A4.62 第一步）— 实测结果与诚实结论

> 日期：2026-09-30 ｜ 主线：A 段战术理解层 ｜ 状态：完成（负结果为主，含 2 个待老程目视的候选）

## 0. 一句话结论

候选池净化（场上脚点门 + 运动地板门）**成功把替补席/观众清出了两两配对池**，
但 **V7 命中总数仍为 9（与 A4.62 巧合相同）**——净化改变的是命中的*构成*，不是*数量*。
这证明：**掩护特异性问题不在候选池，而在「真实球员几何本身 + 队色不可分」**。
净化是必要清理，但不是解锁钥匙。

## 1. 做了什么（可回滚）

- `engine/assign_team.py`：新增 `_scan_frames` / `_purify` / `player_track_ids`，`compute_team_of`
  增加 `player_track_ids` / `motion_frac` / `oncourt_min_frac` 参数；对**不通过两门**的 tid 赋
  `team=None`（掉出配对池，不写进 `ball_tracks_team.json`）。
- 两道数据驱动闸门（均为片段自身统计量的相对量，与 probe 的 `0.5·med_diag` 同风格）：
  - **① 场上脚点门**：脚点在地板掩膜内帧占比 ≥ 0.5（仅统计掩膜有效帧；复用 `court_filter.court_mask`，与相机运动无关）
  - **② 运动地板门**：整段「相邻帧」足点位移累计 `path_len ≥ 0.3·med_diag`（剔坐姿替补/前排静坐观众）
- `engine/screen_specificity_probe.py`：配对池限制为 `team` 非 None 的真实球员 tid（几何+语义判据都干净）。
- `engine/regen_team_purified.py`：一次性用净化版重算全部 28 pilot 段 + 2 batch 段的
  `ball_tracks_team.json`，并落盘 `team_assign_purified.json`（队色心 + 逐 tid 净化统计）。
- `engine/screen_specificity_vis_purified.py`：V7/V8 命中**量化自证**（不靠看图）：
  躯干中位色到段级两队色心距离（抓裁判/残躯）+ 逐人 on_frac/path_len（抓非真实在场）+ IoU（抓同人碎片）。

- 残留误报 = **同人碎片（5）** + **裁判（2）** —— 这两类都*通过*了场上脚点门+运动门（裁判本就在场上移动；同人碎片各自都在场上移动）
- 2 个真实候选：几何（一站一动）+ 在场 + 非同人 + 持球人邻近 全满足；**但队色为 white/white → 异队不可信**

## 4. 为什么净化救不了特异性（根因）

1. **V7 总数不变**：说明真实球员池本身每 28 段就产出 ~9 个「一站一动+异队+持球人邻近」的几何构型。
   这些是 post-up / iso / 短挡拆 / 掩护 等**同构几何**——纯几何+占有权代理无法区分。
   这正是 A4.61 的「语义鸿沟」结论，此处再次独立确认。
2. **队色不可分（white/white）**：28 段中绝大多数 `center_names=['white','white']`。
   2-means 把白衫强行劈成两半，team0/team1 是*任意*的 → V7 的「异队」判据退化为噪声。
   （ep1_s0/1_s1/ep26/27/31/53/70 等少数段有 black/lightgray 另一极，但多数没有。）
3. **裁判两门过**：裁判在场上移动 → 场上脚点门+运动门都过 → 仍在配对池 → 贡献 2 条误报。
4. **同人碎片**：track 中位寿命 1.3–1.7s，同一真人被切成多段 → 两段被当两人 → 5 条误报。

## 5. 诚实判定：候选池不是瓶颈

A4.62 假设「第一瓶颈=候选池被场外人淹没」。实测推翻该假设：
- 场外人（替补/观众）被净化清掉后，V7 数量**没变**。
- 残错误报来自**真实球员几何同构 + 裁判 + 同人碎片 + 队色不可分**——全部在「球员层」，不在「污染层」。

→ 验证链断裂点：**队色分离**（white/white）与**轨迹稳定（同人碎片）**与**裁判剔除**。
  这三点才是真瓶颈，与 A4.62 计划 ③④ 一致，但「候选池净化」作为「第一优先」被证明是**必要但不充分**。

## 6. 下一步（按依赖，待老程裁定）

- ③ **轨迹去重稳定**（合并同人碎片，n_tids ~100→~10）：可直接消掉 5/9 误报（IoU≥0.2 类）。
  轻量做法：配对前按「模态躯干色 + 中位框尺寸 + 活跃区间相邻」合并同人碎片。
- **裁判剔除**：用 `player_pollution_filter.py` 的 `tex_below`（足下纹理高频=座椅/他人身体）
  或队色黑/条纹先验，消掉 2/9 误报。
- **队色分离修复**：white/white 段需换更强队色信号（如号码区/短裤色/边线固定色板），否则「异队」判据作废。
- ⑤ **段级真值**：ep24_s1#00 / ep5_s1#00 两个候选**请老程目视裁定**是否真掩护（裁定权归老程）。

## 8. 老程目视裁定（2026-09-30，决定性负结果）

两个候选**均被老程推翻**：
- **ep24_s1#00 = 场边观众**（非真掩护）。量化自证给 on=1.0 / path=205/210 / d2c=24/63 / iou=0.0 / V8✓，但老程目视=场边观众 → **净化门①漏网**：`court_filter` 已知局限「远端边线人群脚点在地板掩膜内筛不掉」⇒ on_frac=1.0 误判在场；场边观众镜头内移动 ⇒ path 达标 ⇒ 门②也过。
- **ep5_s1#00 = 两队球员紧贴**（非真掩护）。= A4.61 证伪的「贴身防守对位」类：几何与掩护同构，且 ep5 队色 white/white ⇒「异队」判据为噪声 ⇒ 把防守对位当掩护。

**结论升级（决定性）**：净化后 V7/V8 **真掩护命中 = 0（9/9 全误报）**。净化只改变误报*类型*（替补/观众 → 同人碎片/裁判/场边观众/防守对位），没改变*数量*。

**根因链闭合**：几何不可分(A4.61) + 候选池非瓶颈(A4.63) + 队色 white/white 不可分 + 场边观众漏网(court_filter 局限) + 防守对位与掩护几何同构。**「从 broadcast 几何+队色+占有权识别掩护」这条路已被彻底证伪 —— specificity 不可解。**

**路线决策（待老程拍板）**：战术理解层正确入口是 ASR 人声讲解的战术段落定位（A4.57 原料=ASR；纪律=战术语义来自人声，工具不猜）。应**收口「自动识别掩护」**，转向「讲解时段 → 动作级可视化标注」，段级真值由老程人工裁定。
