# A5.1 球员跟踪准确度：量化诊断（老程目标校准后的第一步）

> 日期：2026-09-30 ｜ 老程目标：**最终识别/发现战术；前提=球员和球的移动都识别出来且跟踪准确**
> 结论：**瓶颈定位在「逐帧检测连续性」，不在镜头、不在切镜、不在后处理拼接** → 必须上游修。

## 0. 一句话结论

当前 177 段广播素材的球员跟踪**严重碎片化（碎片倍率 ≈ 9.5×）**；三个探针把根因逐层剥离后定位到
**逐帧人体检测本身不稳**（连大个场上球员的中位 track 寿命也只有 4–5 帧 ≈ 0.4–0.5s），
**镜头基本静止、切镜仅次要贡献、纯后处理拼接有 ≤52% 的硬天花板**。要"跟踪准确"，必须重做上游关联/检测。

## 1. 现状量化（177 段，数字现读）

| 指标 | 值 |
|---|---|
| 中位 每段 ID 数 | **187** |
| 中位 ID 寿命 | **8 帧（≈0.8s）** |
| 中位 人数/帧 | **19.6**（场上应为 10 球员 + 3 裁判 ≈13） |
| 碎片倍率 | **≈ 9.5×** |

> 对照：sas_hou/nop/det（A4.18）中位寿命 8–11 帧、ID 222–260 —— 两批素材同病。

## 2. 探针一：镜头运动量级 → **镜头基本静止**（推翻旧「连续摇镜」说）

`engine/cam_motion_probe.py`（相邻帧 phaseCorrelate 估全局平移，480px 宽降采样）：

| 段 | 每帧位移中位 | max | 响应中位 | 全段累计路径 |
|---|---|---|---|---|
| ?_s0 | 0.53px | 70.1px | 0.70 | 210px |
| ep10_s0 | 0.47px | 23.3px | 0.84 | 164px |
| ep11_s0 | 0.63px | 3.8px | 0.88 | 140px |
| **抽样汇总** | **中位 0.29px** | — | — | **中位 102px** |

**判读**：每帧位移中位 0.29px → 图像空间稳定。⇒ **图像空间拼接无需相机补偿**，且**镜头平移不是碎片主因**。
（旧报告 A4.18 把根因记为"连续摇镜/变焦"——探针数据不支持该说法，予以更正。）

## 3. 探针二：后处理拼接的天花板（含阴性对照）

`engine/stitch_tracks.py`：按「运动外推 + 尺寸相对门」链式合并碎片（不增删检测）。

| 配置(60段, 13296→) | 降幅 | 中位寿命 |
|---|---|---|
| gap=8, alpha=1.2（保守） | −23.3% | 8→11 |
| gap=15, alpha=2.5 | −45.2% | 8→16 |
| gap=40, alpha=2.5（激进，邻人误并风险高） | **−51.6%** | 8→21 |
| **阴性对照** shuffle（前20段） | **−2.9%** | 7→7 |

- 阴性对照证明合并**依赖真实时间连续性**，非退化全并。✅
- 但**即便放到高风险门也只降 ~52%** ⇒ **剩余碎片拼接救不回**。
- 正式参数(gap=8/alpha=1.2)全 177 段：36061→27562（−23.6%），**人数/帧逐帧不变校验 PASS**。

## 4. 探针三：分层 → 碎片不是「场边噪声」

按框高分层（前 40 段，168,582 检测）：

| 层 | 检测数 | 中位寿命 |
|---|---|---|
| 小框 <80px | 58,482 | **4 帧** |
| 中框 80–140 | 72,558 | **5 帧** |
| **大框 ≥140px（明确场上球员）** | 37,542 | **4 帧** |

**判读**：**连大个场上球员也只有 4–5 帧寿命** ⇒ 碎片化**不是**替补/观众小框造成的，是**全场普遍**。

## 5. 探针四：切镜富集 → 次要因素

前 40 段：**新生 ID 帧的 MAD 中位 13.88 = 全帧中位 6.96 的 2.0×**；
新生落在"剧变帧(>4×中位)"比例 **19.4% vs 基线 13.2% ⇒ 富集仅 1.47×**。

**判读**：切镜/角度跳变**确有贡献但解释不了多数碎片**（80.6% 的新生 ID 不在剧变帧上）⇒ 非主因。

## 6. 根因判定与下一步

**根因链**：碎片 ← **逐帧人体检测断续/抖动**（大框小框一视同仁 ≈4–5 帧）← 关联器反复重开 ID。
镜头静止(§2)排除平移；切镜 1.47× 富集(§5)排除主导；拼接 ≤52%(§3)证明后处理救不回。

**下一步（按 ROI，待老程拍板是否重跑上游）**：
1. 🔴 **上游重跟踪（决定性）**：先做**单段对照实验**（调大 track_buffer / 降 new_track_thresh /
   提高检测 imgsz），量 ID 数与"每帧人数不丢"两项，确认增益后再决定是否全量重跑。
   - 注意 A4.18 已证：**单纯调 BotSort 参数会丢人**（nt=0.6 时 11.03→9.06）。故必须"不丢人"为硬门。
2. **弱 ReID 辅助关联**：用 `assign_team.py` 的躯干中位色作关联特征（非聚类，规避 A4.48 的无监督聚类崩）。
   这是把拼接天花板顶上去的正路。
3. **场边剔除**：`court_filter` 脚点门先清出场外人，减少检测抖动源（顺带缓解 19.6 人/帧）。
4. 球侧同理：A4.51/52 精度 69.2% 待提；与球员跟踪共用"连续性"这一主题。
