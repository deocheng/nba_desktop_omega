# A5.5 🔴 B 被证伪 —— ID −55% 是「错并」假象（老程目视裁定 + 物理合理性复核）

> 日期：2026-09-30 ｜ 触发：老程目视抽检图后裁定「**没有准确识别的**」
> 结论：**B 配置（放宽几何门）不可采用**；A5.4 的「−55.1% ID」是**错误合并**造成的假改善。

## 0. 结论先行（含自我纠错）

- 老程看抽检图裁定 B **没有准确识别**。
- 物理合理性复核**证实该裁定**：B 的轨迹帧间位移大跳率是 base 的 **~105 倍**。
- ⇒ **A5.4「ID 36061→16177（−55.1%）」不作数**：ID 变少主要是**把不同球员并成一条轨迹（错并）**，
  不是「把同一名球员正确缝上」。
- 🔴 **方法论教训**：我拿「ID 数 / 寿命」当 KPI，**掩盖了错并**。**数量指标 ≠ 跟踪准确**。

## 1. 物理合理性复核（决定性证据）

判据：轨迹内相邻记录的「帧间位移/帧」；真实球员位移有物理上限，
**错并**会在合并点出现远超本人运动的大跳（跨半场）。

| 版本 | 步数 | 中位步长 | p99 步长 | max | **步长>300px 占比** |
|---|---|---|---|---|---|
| base | 29,343 | 4.88px | 130.3px | 566px | **0.034%（10 条）** |
| **B** | 30,466 | 5.55px | **399.8px** | 710.9px | **3.460%（1054 条）** |

**B 的大跳数是 base 的 ~105 倍**；p99 从 130px 飙到 400px。
⇒ B 的「长轨迹」大量由**跨人拼接**构成 ⇒ 跟踪**更不准**，而非更准。

（8 段样本：ep12_s0 / ep25_s1 / ep7_s0 / ep1_s0 / ep10_s0 / ep24_s1 / ep5_s1 / ep46_s0）

## 2. 第一次诊断（长迹平滑度）与它的坑

`engine/track_quality_probe.py` 先给：长轨迹 (≥20步) 的 `p90/中位` 步长比
base **6.16** → B **13.42**（恶化一倍）。方向一致，但该比值**会被"静止目标"污染**
（静态替补/观众中位步长≈0 ⇒ 任何移动都算"跳"）。
⇒ 故改用**绝对大跳计数**（§1）作为更稳的判据，结论仍然一致。

## 3. 根因：输入检测/跟踪质量的上限，不是关联参数

- **收紧**（base, gate.16）：碎片多（188 ID/段），但错并少（大跳 0.034%）。
- **放宽**（B, gate.60）：ID 少，但**大量错并**（大跳 3.46%）。
- **两头都不对** ⇒ 瓶颈在**逐帧检测的稳定性**（A5.1：场上球员中位寿命仅 4–5 帧），
  参数调优（无论方向）都无法在「碎片」与「错并」之间找到可用平衡点。

## 4. 处置

- **B 不采用**；`tracks_b.json` **保留为证据/可回滚**，但**标记为不可用**。
- **下游继续用 base `tracks.json`**（至少物理上干净），或**不作变更**。
- **新 KPI 确立**：`帧间位移 >300px 占比`（物理合理性）+ `p99 步长` —— 替代「ID 数/寿命」作为跟踪质量门。
  任何后续方案**必须先过此门**，并配老程目视裁定。

## 5. 下一步（待老程定方向）
