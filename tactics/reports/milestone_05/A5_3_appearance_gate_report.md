# A5.3 外观门关联（老程选 C）—— 实验与诚实结论：**本段/多段上 C 未挣到成本，推荐 B**

> 日期：2026-09-30 ｜ 承接 A5.2（调参天花板）｜ 段 ep1_s0 + 4 段复验
> 一句话：**外观信息有效（置换对照证），但宽松几何门本身不引入错并 ⇒ C 不必要，推荐纯几何放宽(B)。**

## 0. 结论先行（含自我推翻）

A5.2 我推荐 C（宽松几何门 + 外观门），理由是"放宽几何门会把相邻球员串号"。
**实测推翻该假设**：
- 置换对照证明外观特征**有效**（打乱后色不连续率 0.065→**0.22**，ID 数 111→186）。
- 但在 gate.40/.60/.90 上，**纯几何(B) 的色不连续率始终维持低位**（≈base），**没有系统性错并**。
- C 反而**多花 ID、略降寿命**，**未挣到成本**。
⇒ **推荐 B（放宽 max_missed + GATE_POS，不加外观门）。**

## 1. C 的实现

`engine/track_appearance.py`：
- 外观特征 = 躯干区中位色（复用 `assign_team.torso_median`，**关联特征，非聚类**）。
- 关联代价 `+= W_APP·颜色距离` + `APP_MAX` 硬门（色差过大直接拒绝）。
- **独立验证信号** = 腿部区(0.55–0.85H)中位色（与关联用的躯干区不同区域）→ 算"合并轨迹色不连续率"。
- **阴性对照** `--shuffle`：打乱外观特征在检测间的分配。

## 2. 单段结果（ep1_s0, 221 帧）

| 配置 | ID 数 | 中位寿命 | 色不连续率 |
|---|---|---|---|
| base mm3 gate.16 | 183 | 9 | **0.043** |
| B40 mm30 gate.40 w0 | 108 | 24 | 0.063 |
| C40 w1.0 | 111 | 21 | 0.065 |
| B60 mm30 gate.60 w0 | 95 | 24 | 0.061 |
| C60 w1.0 | 103 | 23 | 0.057 |
| C60 w3.0 am.20 | 114 | 20.5 | 0.061 |
| **C60-shuffle(对照)** | **226** | 12 | **0.22** |
| B90 mm30 gate.90 w0 | **83** | **32** | 0.052 |
| C90 w3.0 am.20 | 97 | 30 | 0.057 |

- 置换对照 **0.065 vs 0.22** ⇒ 外观信息**真实有效**。
- 但 **C 的色不连续率没比 B 低**（同档位），且 ID 更多 ⇒ **没挣到成本**。
- **连 gate.90（≈648px/帧，物理荒谬地宽）纯几何也才 0.052** ⇒ 宽松门**不引入错并**。

## 3. 颜色代理的分辨力（诚实检查，防"假安心"）

同帧两两躯干色距离（大框）：p10=0.030 / **p50=0.139** / p75=0.217 / p90=0.320；
超过判读阈值 0.22 的占比 **23.1%**。
⇒ 代理**有中等分辨力**（不是"全同色看不见"），但存在盲区（23% 的对太近，互换测不出）。

## 4. 多段复验（5 段，几何放宽 base→B60→B90）

| seg | base ID | B60 | B90 | 人数/帧 | 色不连续 base→B90 |
|---|---|---|---|---|---|
| ep1_s0 | 183 | 95 | 83 | 20.4 | 0.043→0.052 |
| ep10_s0 | 468 | 184 | 151 | 25.6 | 0.087→0.113 |
| ep11_s0 | 317 | 158 | 130 | 26.3 | 0.090→0.117 |
| ep24_s1 | 411 | 166 | 147 | 37.0 | 0.060→0.084 |
| ep5_s1 | 223 | 105 | 91 | 20.4 | 0.107→0.091 |
| **中位** | **317** | **158 (−50%)** | **130 (−59%)** | **不变** | **0.087→0.091** |

- **ID 降 50–59%**，**每帧人数逐段完全不变**（硬门 PASS）。
- **色不连续率非单调**（0.087→0.107→0.091）⇒ 放宽几何门**没有系统性地破坏纯度**。
- 全部跨 5 段复现 ⇒ **单段结论稳住了**。

## 5. 诚实边界

1. 纯度代理**中等分辨力**，**不能替代**老程逐条目视抽检（同色球员互换测不出）。
2. `gate.90` 物理上极端（648px/帧），本机 5 段经验安全，但**拥挤帧仍有理论风险**。
3. 5 段仍是样本；**全量前建议抽 2–3 段目视**。
4. 外观门代码保留（`track_appearance.py`），作为**未来更强 ReID 的接口**，但当前**不启用**。
